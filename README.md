# DJ Library Master — releases

Download the latest **DJ Library Master** for macOS from the
[Releases](../../releases/latest) page (`DJ-Library-Master-<version>-mac.zip`).

Once installed, the app checks this page for new versions, **asks you** before
downloading, verifies the developer's signature and installs the update itself.
You can turn the automatic check off in Settings → Updates.

This repository only contains the published packages. Each release has:

| File | What it is |
|---|---|
| `DJ-Library-Master-<version>-mac.zip` | the full app, for a first install |
| `djlm-app-<version>.zip` | the update package the app downloads |
| `latest.json` | version, notes, checksum and Ed25519 signature |
